# My Portfolio

Personal portfolio site for **Prateek Tripathi** — Full-Stack Developer.

Built with React, React-Bootstrap, and AOS scroll animations.

## Available Scripts

In the project directory, you can run:

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm run build`
Builds the app for production to the `build` folder, minified and ready to deploy.

### `npm test`
Launches the test runner in interactive watch mode.
